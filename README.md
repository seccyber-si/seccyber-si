## About

I'm a systems and network administrator focused on cybersecurity. I build, secure and run IT infrastructure: servers, networks, firewalls and the monitoring that tells you when something is wrong. I'm moving toward DevOps and infrastructure as code.

I share what I learn as practical, defensive cybersecurity on **[seccyber.si](https://www.seccyber.si)**: learning paths, field notes and tech news for people doing the work.

## How I work

- **Understand before changing.** Diagnose from logs and facts, not by trial and error.
- **Security by default.** Least privilege, no secrets in code, labs kept apart from production.
- **Document everything.** Every change has a procedure, a way to verify it and a way to roll it back.
- **Automate what repeats.** Scripts and infrastructure as code over manual steps.
